# Alignment Research Fellowship (ARENA)

This repository contains the datasets, analysis notebooks, and research report
produced during my participation in the Alignment Research Fellowship (ARENA).

The project explores questions related to AI alignment through empirical
analysis, documentation, and reproducible research artefacts.

## Repository Structure

- `data/`  
  Contains the datasets used in the project (JSON format).

- `notebooks/`  
  Google Colab / Jupyter notebooks used for data processing, analysis, and
  experimentation.

- `docs/`  
  Research write-up and supporting documentation (PDF).

## How to Use

1. Review the research report in `docs/` for full context and findings.
2. Open the notebook in `notebooks/` using Google Colab or Jupyter Notebook.
3. Ensure dataset paths are correctly set when running the notebook.

This repository is intended for research transparency, reproducibility, and
